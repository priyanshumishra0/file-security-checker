# File Security Checker

A beginner-level Python cybersecurity project that checks basic file properties and looks for suspicious file types and words.

## Features

- Checks whether a file exists
- Displays file size
- Detects file extension
- Checks suspicious file extensions
- Checks for predefined suspicious words
- Displays basic security warnings

## Technology

Python

## Concepts Used

- Variables
- Input and Output
- If/Else
- Lists
- For Loop
- File Handling
- Exception Handling
- OS Module
- String Methods

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run:

python file_checker.py

4. Enter the file name when asked.

## Example

Enter the file name: test.txt

File found
File size: 25 bytes
File type: .txt
File type looks normal
No suspicious words found

## Disclaimer

This is a beginner educational project. It is not a real antivirus or malware detection system.
